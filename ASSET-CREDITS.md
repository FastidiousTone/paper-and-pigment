# Asset credits and usage

This is an original practice kit, not a redistribution of the uploaded Frontend Mentor challenge. No Frontend Mentor design, photo, font package, or Figma file is included.

- Product illustrations, icons, visual references, product names, and copy: original materials created for this kit using code with ChatGPT. They are not photographs, and the products/brand are fictional. You may use these supplied original materials in this practice project and its published portfolio presentation.
- Fonts: DejaVu Sans and DejaVu Serif. Local TTF files copied from installed DejaVu fonts without changing glyph designs. Preserve public/fonts/LICENSE-DejaVu.txt when redistributing. The original license text controls font usage.
- Vite: installed by npm; subject to its own license and dependency licenses.
- Design references: static PNG/SVG, not an editable native Figma document and not a completed HTML/CSS solution.

Image PNGs are 800x600. The provided data uses PNGs; SVG alternatives show the same composition and do not need separate alt text. Font weights supplied are Sans 400/700 and Serif 400.
